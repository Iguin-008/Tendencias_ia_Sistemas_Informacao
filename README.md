# Tendências em IA - Sistemas de Informação

## 📋 O QUÊ? (WHAT)

Este é um repositório dedicado às **atividades da disciplina de Tendências em Ciências da Computação**, com foco especial em **Inteligência Artificial (IA)** e suas aplicações no contexto de Sistemas de Informação. O repositório contém materiais de estudo, exercícios práticos, projetos e discussões sobre os temas mais atuais da área.

## 🎯 POR QUÊ? (WHY)

A disciplina existe para preparar estudantes de Sistemas de Informação a compreender e se adaptar às rápidas transformações tecnológicas, especialmente no campo da IA. O objetivo é:
- Desenvolver pensamento crítico sobre tendências emergentes
- Aplicar conhecimentos teóricos em casos práticos
- Preparar para os desafios profissionais do mercado moderno
- Explorar a interseção entre IA e Sistemas de Informação
